# Balance revert list (survev balance.txt)

> Every change line of survev's `balance.txt` as a structured revert entry, plus the fork differences that `balance.txt` does not log.
> `balance-revert.json` is an array of `{section, target, field, forkValue, originalValue, line, confidence, note, refs, maps?, balanceValue?, unlisted?}`;
> `line` is the `balance.txt` line number (`null` for unlisted entries) and `balanceValue` is the change as `balance.txt` words it.
> To get v0.8.82 behaviour, set each target to `originalValue`. Entries whose original is `absent` mean "remove"; fork-only content goes away with the ids marked `fork` in `fork-vs-original.md`.

## Method

- `balance.txt` is the fork's own log of balance changes "to keep track of differences from the original game"; it has 353 lines (352 newline-terminated plus a final line 353) in sections Stat Changes, Misc Changes, Cache Changes and Other Changes (by patch) [src:balance/1, balance/3, balance/143, balance/149, balance/167] [H]
- Fork values were read from survev HEAD (c6185e31): `shared/defs/gameObjects/*`, `shared/defs/maps/*` (loaded as merged `MapDefs`), obstacle loot in `shared/defs/mapObjects/obstacles/*`, `PerkProperties` and `GameConfig` [src:survev/shared/defs/mapDefs.ts:1, survev/shared/defs/gameObjects/perkDefs.ts:4, survev/shared/gameConfig.ts:415] [H]
- Original stat values were read from the original v0.8.82 client defs that survev imported in its first commit `9f64948d`, so stat entries have two independent sources (balance.txt wording and the original client) [src:derived/git-9f64948d] [H]
- Every stat original in this list (bullet, gun, throwable, explosion and melee fields, dual-pistol ammo, strobe delay, bag sizes) was re-checked against the 2026 relaunch client bundle and matches it, except the server-only fields `freezeDuration` and `dropRandomLoot`, which that client does not have; the relaunch client also carries the original obstacle loot (`crate_12`, `crate_13`, class crates, caches, `crate_02sv`) [src:kong/relaunch-client-defs] [H]
- The original client has no loot tables (`main.ts` there has `lootTable: {}`), so loot and spawn originals come from survev's own pre-fork reconstruction: the snapshot at `ae55c9a8` (2025-07-01), before the first dated balance.txt block (0.1.2, 2025-07-23) [src:derived/git-9f64948d:src/defs/modes/main.ts:62, derived/git-ae55c9a8, balance/170] [H]
- survev labels that reconstruction itself: "this loot table is not the original one so its not accurate", `?` = guesses from statistics, `!` = uncertain leak data [src:survev/shared/defs/maps/baseDefs.ts:90, survev/shared/defs/maps/baseDefs.ts:91, survev/shared/defs/maps/baseDefs.ts:92] [H]
- Each loot or spawn entry was also checked against survev just before the change (the parent of the commit that made it); `[H]` = that snapshot matches balance.txt's left-hand value, `[L]` = it contradicts balance.txt, `[M]` = only one source [src:derived/snapshot-check] [H]
- Role loadouts and perk constants are server-side, so their originals come from survev history before the fork changes: `70cd674a` (2025-03-19) for roles and perks, `4a45bce2^` (2025-01) for the Lone Survivr perk roll [src:derived/git-70cd674a, derived/git-4a45bce2] [H]
- 320 entries come from balance.txt (stats 71, perks 10, roles 11, lootTables 197, mapSpawns 28, other 3) and 305 unlisted differences were found (mapSpawns 164, roles 4, stats 17, perks 2, lootTables 116, other 2); 14 of them (Cobalt class perks, Faction promotion order, seven obstacle drops, the Savannah SV-98 duplicate, the bugle muzzle offset, the downed-damage buffer and the Commander flare auto-fire) were added in a second pass that diffed the 2026 relaunch client against survev HEAD [src:derived/balance-revert-json] [H]
- 197 distinct balance.txt lines carry an entry; the other lines are headers, blank lines, notes or continuation lines of a multi-step change [src:derived/balance-revert-json] [H]
