# Perks

> Every perk def in survev `shared/defs/gameObjects/perkDefs.ts` (48 ids) with its UI name (en + ko), description, the server-side effect traced in `server/src`, the modes that hand it out, and original v0.8.82 values next to fork changes.
> The original surviv server was never published: survev's server numbers are reconstructions. Where a wiki gives an original number it is listed next to the survev value.
> "orig" defs come from survev's first commit `9f64948d` (decompiled v0.8.82 client, `src/defs/perkDefs.js`), cited `derived/survev@9f64948d:<path>:<line>`. Original localization comes from commit `a14ab228` (2024-02-24, "add missing localization files ... yanked from survivreloaded-client ... remove post kong locale data"), cited `derived/survev@a14ab228:client/l10n/<lang>.json:<line>`; survev later rewrote many ko strings, so the ko column shows the original first and the fork wording in brackets.
> Git facts are cited `derived/survev-git-<commit>`. Abbreviations below: P = `server/src/game/objects/player.ts`, W = `server/src/game/weaponManager.ts`, B = `server/src/game/objects/bullet.ts` (citations always spell out the full path).

## How perks are held, picked up and dropped

- The server keeps a list of perks per player, each with `droppable`, `replaceOnDeath` and `isFromRole` flags [src:survev/server/src/game/objects/player.ts:1156-1205] [H]
- Loot perks are `droppable`; perks from roles and helmets are not, and do not use up the loot-perk slot [src:survev/server/src/game/objects/player.ts:1170-1205] [src:survev/server/src/game/objects/player.ts:3884-3891] [src:wikigg/Perks] [H]
- One loot-perk slot: picking up a second loot perk swaps it and drops the old one. The slot count is the backpack's `maxPerks` (default 1); the fork-only `backpack04_cloud` "Experimental Pack" has 2 [src:survev/server/src/game/objects/player.ts:3946-3975] [src:survev/shared/defs/gameObjects/gearDefs.ts:917-926] [src:wikigg/Perks] [H]
- A duplicate perk returns "AlreadyEquipped" (original l10n `game-item-already-equipped` "Item already equipped!") [src:survev/server/src/game/objects/player.ts:3936-3940] [src:derived/survev@a14ab228:client/l10n/en.json:257] [H]
- (fork) A player with no loot perk and 4 or more perks gets "MaxPerks" ("Maximum perks equipped!") and cannot pick up another; added in fork commit f001d961 (2026-03-29, "Stops you from picking up 5 perks since the UI can't support it"); the original only has a net serialization limit `MaxPerks: 8` [src:survev/server/src/game/objects/player.ts:3952-3958] [src:derived/survev-git-f001d961] [src:survev/client/src/en.json:333] [src:derived/survev@9f64948d:src/net/net.ts:146] [H]
- The HUD had 3 perk slots in the original client (`ui-perk-0..2`, `perkUiCount = 3`); the fork raised it to 4 in commit 1cf4b8fd (2025-06-10) for the 4-perk Lone Survivr (fork) [src:derived/survev-git-1cf4b8fd] [src:survev/client/src/ui/ui2.ts:35] [src:wikigg/AP_Rounds] [H]
- Picking up a perk makes the player emote `emote_<perk id>` if that emote exists (true for the 10 trick/treat perks) [src:survev/server/src/game/objects/player.ts:3942-3945] [H]
- The droppable perk can be dropped from the HUD; on death droppable perks drop as loot, and a perk rolled from `halloween_mystery` drops back as `halloween_mystery` [src:survev/server/src/game/objects/player.ts:4225-4234] [src:survev/server/src/game/objects/player.ts:2977-2990] [H]

- Helmets with a `perk` field grant it while worn and remove it when dropped or swapped: `helmet03_lt_aged` → `firepower` (desert), `helmet03_potato` "K-pot-ato" → `rare_potato` (potato) [src:survev/shared/defs/gameObjects/gearDefs.ts:727-756] [src:survev/server/src/game/objects/player.ts:3874-3891] [src:survev/server/src/game/objects/player.ts:4172-4174] [src:derived/survev@9f64948d:src/defs/gearDefs.js:597-626] [H]
- Role perks are added on promotion with `isFromRole` and removed with the role [src:survev/server/src/game/objects/player.ts:932-984] [src:survev/server/src/game/objects/player.ts:1105-1122] [H]
